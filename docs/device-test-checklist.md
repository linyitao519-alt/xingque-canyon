# 真机测试清单（v10 · 中路）

打开方式：电脑上 `npm start`，手机与电脑连同一 Wi-Fi，浏览器打开终端里打印的 `http://<电脑IP>:5173/`，横屏。iPhone 建议"添加到主屏幕"后从图标进入（全屏、没有地址栏）。
先点一下屏幕任意处（解锁音频）。右上角可静音 / 全屏。

| # | 项目 | 怎么测 | 合格 | 桌面浏览器（Chromium 触摸仿真 844×390，已测） | 真机（待填：机型 / 系统 / 浏览器） |
|---|---|---|---|---|---|
| 1 | 摇杆启动 | 左半屏任意处按下立刻推 | 手指一动角色就走，没有死区迟滞；摇杆出现在按下的位置 | 通过（e2e_mobile 摇杆项） | |
| 2 | 急转弯 | 推满后快速画圈、左右甩 | 角色立即跟向；贴图不左右乱翻；星盘不甩飞 | 通过（朝向带回差；星盘每帧位移 ≤ 1.0 世界单位，e2e_media） | |
| 3 | 松手停步 | 跑动中松手 | 立即停，不滑步；0.15 秒内回到待机，不原地踏步 | 通过（anim 测试） | |
| 4 | 边走边瞄准 | 左手走位，右手按住技能拖动，再拖到取消区松手 | 两指互不干扰；镜头朝落点平移顺滑、松手后回正；取消区松手不放技能、不进冷却 | 通过（双指、取消、镜头每帧位移最大 12.8px / 平均 3.7px） | |
| 5 | 塔提示 | 走进红方一塔射程：先在塔出框的位置被锁定，再走近到塔在画面内；退出射程；带兵进塔看塔转火 | 被锁定且塔出框 = 屏边红箭头；塔在画面内 = 脚下红环（先闪一下再常亮）；解除后很快消失；框边不来回闪 | 通过（e2e_camera 8 项） | |
| 6 | 帧率 | 双方兵线 + 英雄在桥上交战时观察 20 秒 | 稳定 60（或设备刷新率），无明显掉帧；机身不烫 | 无参考意义（无头浏览器逐帧步进，不反映真机性能） | |
| 7 | 音效延迟 | 普攻、放技能、被塔打 | 声音与出手/命中画面同步（体感 < 0.1 秒）；切后台回来仍有声；静音键有效 | 只验证了"事件 → 播放调用"的次数与时机；实际出声延迟必须真机听 | |
| 8 | 安全区 | 刘海 / 灵动岛一侧、底部横条 | 小地图、摇杆、技能键、计时条都不被遮挡 | 通过（用 `?safe=47,47,0,21` 模拟） | |
| 9 | 一局结算 | 打完一局（或 `?auto=1&speed=8` 快进） | 出胜负面板，点"再来一局"能重开 | 通过 | |

待确认的三项手感（确认后再做另外两路和基地）：镜头屏高 102、英雄移速 84、触控布局。
对比用参数：`?viewh=120`（旧屏高）、`?towers=v8`（旧塔位）、`?aimcam=0`（关技能取景）、`?hint=0`（关塔提示）。
